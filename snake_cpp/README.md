
# 🐍 Консольная змейка на C++

Это мой первый пет-проект на C++. Цель — не просто написать игру, а сделать её «по-взрослому»: с чистой архитектурой, понятным кодом и постепенным усложнением. Проект создается в Visual Studio и версионируется через Git.

## 🎯 Цель проекта
- Закрепить базу C++: структуры, массивы, функции, циклы.
- Понять, как работает игровой цикл (Game Loop).
- Научиться обрабатывать ввод в реальном времени (без Enter).
- Отработать навыки работы с Git и GitHub.

## 🛠 Стек
*   **Язык:** C++ (стандарт C++17 или выше)
*   **Среда разработки:** Visual Studio (MSVC)
*   **Контроль версий:** Git / GitHub
*   **ОС:** Windows (используются `<conio.h>` и `<windows.h>`)
